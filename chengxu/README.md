# DIOR 限量臻选小程序

一个高端奢侈品限量产品预订微信小程序，专为 DIOR 品牌打造，体现法式优雅与奢华品质。

## 项目概述

本项目是一个微信小程序，定位高端奢侈品市场，通过限量产品预订提升品牌影响力。采用黑色、白色、金色的配色方案，体现 DIOR 品牌的高端调性。

## 核心功能

### 1. 限量产品预订
- 产品展示页面，显示限量商品图片、描述和库存
- 预订表单，包括选择数量、规格和提交功能
- 实时库存更新和限制逻辑
- VIP会员优先购买权限

### 2. 品牌故事展示
- 品牌历史和产品细节页面
- 支持文本、图片和视频内容
- 设计师故事和工艺传承介绍
- 全球影响力和可持续发展理念

### 3. 微信支付集成
- 微信支付API集成
- 支付页面和订单管理
- 多种配送方式选择
- 优惠券和发票功能

### 4. 用户体验优化
- 多步骤购买流程（浏览 → 预订 → 支付 → 确认）
- 个性化推荐功能
- VIP会员体系
- 社交分享功能

## 安装和运行

### 环境要求
- 微信开发者工具 (版本 2025.06+)
- Node.js (推荐 v14+)
- 微信小程序开发账号

### 安装步骤

1. **克隆项目**
   ```bash
   git clone [项目地址]
   cd chengxu
   ```

2. **配置微信开发者工具**
   - 打开微信开发者工具
   - 选择"导入项目"
   - 选择 `chengxu` 文件夹
   - 填写 AppID (申请小程序后获得)

3. **配置云开发环境**
   - 在 `app.js` 中修改云开发环境ID
   ```javascript
   wx.cloud.init({
     env: 'your-cloud-env-id', // 替换为你的云开发环境ID
     traceUser: true
   });
   ```

4. **配置API接口**
   - 在 `utils/api.js` 中修改API基础URL
   ```javascript
   const BASE_URL = 'https://your-api-domain.com' // 替换为实际API地址
   ```

### 开发环境运行

1. 在微信开发者工具中点击"编译"
2. 在模拟器中预览效果
3. 使用真机调试测试完整功能

## API 接口

项目使用 RESTful API 设计，主要接口包括：

- **用户管理**: 登录、注册、信息更新、VIP申请
- **产品管理**: 产品列表、详情、搜索、推荐
- **订单管理**: 创建订单、支付、查询、取消
- **预订管理**: 创建预订、库存更新、状态查询

详细的API文档请参考 `utils/api.js` 文件。
