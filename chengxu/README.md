# 上线了 - 登录页面小程序

这是一个仿照"上线了"网站登录页面设计的小程序，具有现代化的UI设计和完整的交互功能。

## 功能特性

- ✨ 现代化的紫色渐变背景设计
- 📱 手机号/邮箱登录切换
- 🔐 表单验证功能
- 📞 支持多国家区号选择
- 🎨 流畅的动画效果
- 📱 响应式设计，支持移动端
- 🔄 登录状态反馈

## 文件结构

```
chengxu/
├── index.html          # 主页面文件
├── style.css           # 样式文件
├── script.js           # JavaScript交互文件
└── README.md          # 项目说明文档
```

## 使用方法

1. 直接用浏览器打开 `index.html` 文件即可运行
2. 或者在本地搭建简单的HTTP服务器：
   ```bash
   # 使用Python 3
   python -m http.server 8000
   
   # 使用Node.js (需要先安装http-server)
   npx http-server
   ```

## 功能说明

### 登录方式切换
- 点击"手机"或"邮箱"按钮可以切换登录方式
- 手机登录支持选择国家区号（+86, +1, +44等）
- 邮箱登录提供标准的邮箱输入框

### 表单验证
- 手机号验证：检查是否为有效的中国手机号格式
- 邮箱验证：检查是否为有效的邮箱格式
- 密码验证：检查是否输入密码

### 交互效果
- 输入框聚焦时有微妙的缩放效果
- 登录按钮有hover动画效果
- 登录过程有加载状态显示

### 其他功能
- 短信验证码登录（占位功能）
- 忘记密码（占位功能）
- 第三方登录（占位功能）
- 免费注册（占位功能）

## 技术栈

- HTML5

## 自定义修改

### 修改颜色主题
在 `style.css` 中修改以下变量：
```css
/* 背景渐变 */
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);

/* 登录按钮颜色 */
background: linear-gradient(135deg, #8BC34A 0%, #4CAF50 100%);

/* 链接颜色 */
color: #667eea;
```

### 添加新功能
在 `script.js` 中可以添加更多交互功能，比如：
- 实际的API登录接口调用
- 更复杂的表单验证
- 记住登录状态
- 多语言支持
